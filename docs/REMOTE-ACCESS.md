# 远程访问方式说明（LAN / 公网 / FN Connect 中继）

LibreTV-fnOS 在一个应用里包含两种播放链路：

| 链路 | 入口 | 流量路径 | 适用场景 |
|---|---|---|---|
| A. 影视兼容代理（NAS 中转） | `http://<NAS-IP>:8091/`（LibreTV 顶部「影视库」） | 客户端 → NAS → 源站 | 局域网、公网直连（8090/8091 可达） |
| B. 飞牛影视原生直连（客户端拉源站） | 飞牛影视原生 Web/App | 客户端 → 源站（不经过 NAS/中继） | FN Connect / 中继、以及所有原生客户端 |

## 结论（已实测）

- **局域网 / 公网直连**：A 与 B 都可用；建议用 A（兼容性最好，绕开源站防盗链与客户端代理）。
- **FN Connect / 二级域名 / 飞牛中继**：飞牛中继只转发 fnOS 主网关端口（443/5666/5667），
  **8090 / 8091 不可达**。此时请观看者使用 **飞牛影视原生页面/App**（链路 B）：
  实测中继环境播放成功，视频流由客户端直连源站，**不占 NAS 与中继带宽**。
- LibreTV（8090）本身也仅用于管理员在局域网/公网下搜索与同步；远程观看者无需访问它。

## 中继观看步骤

1. 通过 FN Connect（`https://fnos.net/<你的FN ID>/` 或 `https://<id>.fnos.net/`）登录；
2. 打开 **飞牛影视**（不要点 LibreTV 里的「影视库」，那是 8091 入口）；
3. 播放 STRM 媒体库中的影片。

## 排障

- 个别源在中继/远程网络下可能无法播放：多为**源站 CDN 到客户端网络不可达或防盗链**
  （实测同一 URL 在全球不同节点存在 200/404 差异）。处理：换一个源重新点「加入媒体库」，或在局域网/公网下用 8091 兼容代理观看。
- LibreTV 的 6 小时增量同步会保持直链新鲜；失效时重新同步即可。
- 中继下若页面本身打不开：确认 FN Connect 状态与 fnOS 网关；这与本应用无关。
